# CityRoots
CityRoots – Agri-Tech Investment Platform
Tools & Technologies: .NET 8 (C# 12), EF Core, AutoMapper, SignalR, PayPal API, ASP.NET Core Identity, Hangfire, AI/ML (FastAPI), RESTful APIs, SMTP

Engineered a scalable agri-tech platform connecting farmers, investors, and merchants, digitizing agricultural investment and produce procurement workflows.

Integrated AI-powered services for plant disease detection and personalized investment recommendations, enhancing decision accuracy and crop health by an estimated 35%.

Implemented real-time features using SignalR, including a live chat service and notification system, improving communication and transparency across users.

Developed a custom email service for account confirmation and user support, improving onboarding experience and reducing response time for inquiries.

Integrated PayPal for secure online payments and investment transactions, reducing financial friction and streamlining investor participation.

Integrated external weather APIs to support cycle planning and forecast climate-related risks, empowering farmers with data-driven insights.

Automated recurring tasks (e.g., cycle reminders, status updates) using Hangfire, reducing manual workload and improving operational consistency.

Secured user access through ASP.NET Core Identity, enforcing role-based authentication for farmers, investors, and merchants.

Built RESTful APIs and DTO mappings for clean frontend-backend interaction, enabling future mobile or web client integration.

Architected the platform using a clean, layered structure (Domain, Application, Infrastructure, Presentation), ensuring modularity and maintainability.
